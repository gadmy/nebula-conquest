# Images des régimes politiques

Une image par régime, à déposer dans ce dossier avec exactement ces noms :

| Fichier | Régime |
|---|---|
| `democratie.jpg` | Démocratie |
| `republique.jpg` | République |
| `technocratie.jpg` | Technocratie |
| `monarchie.jpg` | Monarchie |
| `empire.jpg` | Empire |
| `dictature.jpg` | Dictature militaire |
| `theocratie.jpg` | Théocratie |
| `oligarchie.jpg` | Oligarchie marchande |
| `commune.jpg` | Commune agraire |

- Format : JPG, paysage, environ **600 × 320 pixels** (rapport proche de 2 pour 1). L'image est recadrée au centre pour remplir le haut de la carte.
- Poids : moins de 150 Ko chacune si possible.
- Tant qu'une image manque, la carte affiche l'icône du régime à la place.
