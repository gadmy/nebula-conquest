# NEBULA CONQUEST — 12 prompts d'images pour la Chronique

Chaque prompt est **complet** : il suffit de le copier-coller tel quel dans ton outil d'images IA. Le style commun est déjà inclus dans chacun, pour que les 12 images se ressemblent.

- **Format** : 16:9 (paysage). Avec Midjourney, ajoute `--ar 16:9` à la fin du prompt.
- **Noms des fichiers** : `scene01.jpg` à `scene12.jpg`.
- **Prompt négatif** (si ton outil a une case « à éviter ») :

`text, letters, words, logo, flag, emblem, watermark, signature, blurry, low quality, deformed hands, extra fingers, cartoon, anime`
